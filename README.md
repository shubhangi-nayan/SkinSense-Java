SkinSense. Skincare Detection System

Overview

This is a program that uses Java to help people figure out what kind of skin they have and gives them tips on how to take care of it. It is really simple to use you just have to answer a questions.

Features

We have a quiz with 5 questions and you have to rate your answers on a scale of 1 to 4

It tells you what kind of skin you have like if it is oily or dry or sensitive or if you get acne a lot or if it is a mix of everything

You get to see how you did on the quiz with little bars that show your progress

We give you customized tips on how to take care of your skin

You can take the quiz again if you want to

Requirements

You need to have Java JDK 8 or something newer

You can use it on your computer with the terminal or command prompt or any Java program

How to Run

First save the file as SkinSense.java

Then you have to compile it

You do this by typing

javac SkinSense.java

Then you run it

You do this by typing

java SkinSense

How to Use

You have to answer 5 questions about your skin

For each question you have to type 1, 2 3 or 4:

1 means it does not happen all

2 means it happens a little bit

3 means it happens kind of a lot

4 means it happens very much

Then you get to see what kind of skin you have and what you should do to take care of it

You can choose to take the quiz again or just quit

Limitations

This is just a basic quiz it is not like going to the doctor or anything

You have to use it on your computer it does not have a fancy interface

It only knows about the most common skin types
